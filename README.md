# Mijn Vermogen

Persoonlijk dashboard om al je geld in één oogopslag te zien: bankrekeningen, spaarrekeningen, brokers/beleggingen, crypto, pensioensparen, vastgoed, cash en schulden.

## Gebruik

Geen installatie of build nodig — open `index.html` in je browser, of host de map via GitHub Pages (Settings → Pages → branch kiezen).

- **+ Rekening**: voeg een rekening toe (naam, instelling, categorie, munt, saldo).
- **Brokers / crypto / pensioen**: voeg posities toe (ticker, aantal, koers); de waarde wordt automatisch berekend.
- **Vreemde munten**: stel wisselkoersen in via ⚙ Instellingen; alles wordt omgerekend naar euro.
- **Verloop**: elke dag dat je iets bijwerkt wordt een momentopname bewaard, zodat je je netto vermogen over tijd ziet.
- **👁 Verberg**: vervaagt alle bedragen (handig in het openbaar).
- **Back-up**: Instellingen → Exporteren/Importeren (JSON).

## Privacy

Alle gegevens blijven in de `localStorage` van je eigen browser; er wordt niets verstuurd. Een andere browser of toestel ziet dus je data niet — gebruik export/import om ze over te zetten.
